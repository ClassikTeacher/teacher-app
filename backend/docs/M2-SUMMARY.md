Контракты для следующих вех:

- M3-02 подписывается на `group.member_added` / `group.member_removed` / `group.archived` (`membershipId`, `at`) и на `link.ended` (`groupIds`) — применение к будущим занятиям.
- M4-06 подписывается на `link.ended` (`reason`, `message`) — отмена будущих занятий и заявок; M5 — закрытие ДЗ; материалы — доступ по умолчанию закрывается.

- M6-01 реализует `JournalsPort.ensureForLink` (три журнала на предмет связи).
