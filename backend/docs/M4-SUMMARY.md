# Фаза M4 «Отмены, заявки и уведомления» — итоги (2026-10-21)

Цель вехи: «тихих отмен нет, все в курсе» — достигнута. Сквозные сценарии UC-16…UC-23, UC-37, UC-41 покрыты e2e с подменой Telegram API; каждая задача прошла ревью субагентом `code-reviewer`, HIGH/MEDIUM-находки исправлены (журнал — `PROGRESS.md`, раздел M4). Полный прогон: 81 файл, 272 теста, все зелёные.

Контракты для следующих вех:

- M5/M6: типы `homework.*`, `submission.*`, `grade.added`, `material.granted`, `report.sent` добавляются в `NOTIFICATION_TYPES` и `CC_CONFIGURABLE_TYPES`; NTF-07 для отметок (дайджест) — M6.
- Этап 2: «Предложить другое время», объявления, REST для настроек уведомлений (сейчас только боты).
