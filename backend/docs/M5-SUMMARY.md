Контракты для следующих вех:

- M6-01: `submission_review.grade_entry_id` и `assignment.grading = { kind: 'journal', journalId, scaleId }` — «⭐ Оценить» в карточке сдачи сейчас отвечает «появится с журналами»; выставление из проверки ДЗ пишет запись со ссылками на задание и занятие (`assignment.assigned_lesson_id`).
- M6-03: `HomeworkQuery.stats(teacherId, studentId, range)` — вовремя / с опозданием / не сдано / принято / возвращено; `material_view` — просмотры материалов.
- M7-01: `FileDeliveryService.sendMany` и очереди отправки — нагрузочный тест альбомов; `OverdueAssignmentsJob` — батчи по 200 с SKIP LOCKED.
- Этап 2: `POST /files/uploads` (подписанная ссылка на загрузку > 20 МБ), голосовые сдачи (`voice` распознаётся и отклоняется), удаление EXIF (HW-04), разделы подборок (Р-30), оценка «journal» в REST.

Отложено (бэклог): sweep объектов S3 без строк (падение между `put` и коммитом; ключи с префиксом учителя позволяют lifecycle-правило), тест clamd-клиента на фейковом TCP-сервере, пакетный `publish` для больших групп (сейчас один запрос занятий на цель), N+1 в `ContentAccessQuery.openGrants` по учителям (проверка связи и фичи в цикле), уведомление об исключении из группы по материалам (сейчас доступ пропадает молча — MAT-02).
