# Фаза M1 «Фундамент» — итоги (2026-10-19)

Цель вехи: «учитель приглашён и попал в рабочий бот» — достигнута, сквозной сценарий покрыт e2e с подменой Telegram API.

| Задача | Результат                                                                                                                                                          |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| M1-01  | NestJS 12/Fastify, strict TS, ESLint/Prettier, Compose (PG16, Redis 7, RustFS), Dockerfile, CI со smoke-тестом образа, zod-конфиг, pino + correlation_id           |
| M1-02  | Drizzle + ручные SQL-миграции с checksum, транзакции через ALS (savepoint, afterCommit), Testcontainers, БД на файл тестов                                         |
| M1-03  | аккаунты, роли (один SA), приглашения (хеш, 72 ч, привязка, отзыв), блокировки, seed:superadmin, Bearer-JWT, admin REST                                            |
| M1-04  | AuthBot: анкета онбординга, INV-04, возобновление; шлюз на 4 токена, сессии Redis, i18n, движок диалогов, дедуп update_id, граница ошибок                          |
| M1-05  | StaffBot: меню по ролям/фичам, модули разделов, центральная авторизация, команды по чатам, bot_chat, my_chat_member                                                |
| M1-06  | каталог фич, три уровня, зависимости, лимиты, кеш, FEATURE_DISABLED, раздел «Администрирование», REST фич                                                          |
| M1-07  | audit_log (append-only, GET /admin/audit), outbox + BullMQ, notification + планировщик SKIP LOCKED со сверкой, очереди на бота, admin.* потребитель, UC-40, worker |
| M1-08  | предметы и типы файлов: бот-разделы, REST, денилист опасных типов                                                                                                  |
| M1-09  | POST/DELETE /system/super-admin/transfer (X-System-Key, лимитер), подтверждение в AuthBot кнопками, аудит, уведомления                                             |

Цифры: 8 миграций, 190 файлов TS/SQL/FTL, 28 тестовых файлов (40 unit + 65 integration/e2e), все зелёные; 9 ревью субагентом (1 BLOCK исправлен, 0 CRITICAL). Решения T-01…T-14 — DECISIONS.md, журнал ревью — PROGRESS.md.

Отложено: request_users (этап 2), guard «роль + контекст» (M2), лимит на чат/тихие часы/копии (M4-05), отдельный секрет вебхука на бота, Redis-lock по чату для реплик. Боты к реальному Telegram не подключались (нет токенов).
