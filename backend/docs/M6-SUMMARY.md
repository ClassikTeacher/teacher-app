Контракты для следующих вех:

- M7-01: `GradeEntryRepository.listByJournals` и `ReportsUseCase.build` читают записи периода одним запросом на связь — нагрузочный тест отчёта на ученика с большим журналом; `IcsUseCase.feed` — лента учителя со 100 учениками (один запрос занятий, гидратация участников).
- M7-04: публичный `GET /ics/{token}.ics` защищён только энтропией токена (256 бит) и хешем в БД; ограничение частоты на эндпоинт по IP не ставилось — добавить вместе с общим лимитером API.
- Этап 2: `assignment.grading = { kind: 'journal' }` — автоматический выбор журнала при «Оценить» (сейчас журнал выбирается в диалоге); картинки значений кастомной шкалы (`grade_scale_value.image_file_id`); учебные периоды и другие шкалы (`academic_period`, E2-15); графики тестов картинкой и PDF-отчёт (E2-06); автоотчёт в конце месяца (E2-13); REST для ученика и родителя над `GradebookQuery.personCard`, `ReportsUseCase.personReport` (E3-02).

Отложено (бэклог): дайджест отметок (`grade.digest`) не перечисляет сами отметки — только ссылку на экран; пагинация записей журнала в ботах (показываются последние 15); `grade_entry_history` не выводится в ботах (хранится для JRN-05, читается репозиторием); лимит ожидающих отметок на журнал — константа (20), не настройка учителя.
